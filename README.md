# Баг-репорты и тестовая документация (QA Portfolio)

## 📌 О проекте

Данный проект создан для практики ручного тестирования программного обеспечения (Manual QA).

В рамках проекта проводится функциональное тестирование учебного интернет-магазина SauceDemo, оформляются баг-репорты и подготавливается тестовая документация.

Цель проекта — продемонстрировать базовые навыки начинающего QA-инженера.

## 🎯 Цели проекта

- Практика ручного и исследовательского тестирования.
- Проверка функциональности веб-приложения.
- Выявление и документирование дефектов.
- Составление понятных и воспроизводимых баг-репортов.
- Определение серьёзности дефектов (Severity) и приоритета исправления (Priority).
- Документирование результатов тестирования.
- Подготовка проекта для QA-портфолио на GitHub.

## 🧪 Объект тестирования

- **Приложение:** SauceDemo
- **Ссылка:** https://www.saucedemo.com/
- **Тип тестирования:** ручное функциональное тестирование
- **Инструменты:** браузер, Visual Studio Code, Markdown, GitHub
- **Основные области проверки:** авторизация, каталог товаров, корзина, оформление заказа

## 🐞 Баг-репорты

Для каждого подтверждённого дефекта будет создан отдельный файл с описанием проблемы.

Баг-репорт будет содержать:

- **ID дефекта** — уникальный идентификатор.
- **Название** — краткое описание проблемы.
- **Окружение** — условия проведения тестирования.
- **Предусловия** — условия, необходимые для воспроизведения.
- **Шаги воспроизведения** — последовательность действий.
- **Ожидаемый результат** — корректное поведение приложения.
- **Фактический результат** — поведение приложения при проверке.
- **Severity** — степень серьёзности дефекта.
- **Priority** — приоритет исправления.
- **Статус** — текущее состояние дефекта.
- **Доказательства** — скриншоты или другие подтверждающие материалы.

Дефекты будут добавляться только после фактической проверки и подтверждения воспроизводимости.

## 📄 Тестовая документация

В папке `test-documentation/` будут размещены следующие документы:

- `test-environment.md` — описание окружения, в котором проводится тестирование.
- `test-summary.md` — сводка выполненных проверок, результатов и обнаруженных дефектов.

## 🛠 Используемые инструменты

- **SauceDemo** — учебное приложение для тестирования.
- **Visual Studio Code** — редактор для подготовки документации.
- **Markdown** — формат оформления документов.
- **Git и GitHub** — система контроля версий и публикация проекта.

## 📊 Результаты тестирования

Результаты будут добавляться по мере выполнения проверок.

В итоговой сводке будут отражены проверенные функциональные возможности, результаты тестирования и подтверждённые дефекты.
