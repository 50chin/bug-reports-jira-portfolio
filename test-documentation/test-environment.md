# Описание тестового окружения (Test Environment)

Данный документ описывает конфигурацию оборудования и программного обеспечения, которые использовались для проведения ручного тестирования приложения SauceDemo

## 1. Аппаратное обеспечение (Hardware)

- **Устройство:** Персональный компьютер (ноутбук)
- **Операционная система:** macOS
- **Разрешение экрана:** 1920 × 1080 px (основное)
- **Дополнительное разрешение:** 480 px (в режиме эмуляции мобильного устройства)

## 2. Программное обеспечение (Software)

- **Браузер:** Google Chrome (актуальная стабильная версия)
- **Инструменты разработчика:** Chrome DevTools (режим Toggle Device Toolbar для проверки адаптивности)
- **Редактор кода/документации:** Visual Studio Code
- **Система контроля версий:** Git / GitHub
- **Баг-трекер:** Jira (для оформления найденных дефектов)

## 3. Тестовые данные (Test Data)

Для проверки функциональности использовались предоставленные разработчиками учебные учетные записи:


| Логин      | Пароль   | Назначение                                                                                                                                                                                               |
| --------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `standard_user` | `secret_sauce` | Эталонный пользователь. Используется для проверки корректного поведения интерфейса и функционала                             |
| `visual_user`   | `secret_sauce` | Пользователь с намеренно внедренными визуальными и UI-дефектами. Используется для тренировки навыков поиска багов |

## 4. Объект тестирования (System Under Test)

- **Приложение:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Тип приложения:** Веб-приложение (интернет-магазин)
- **Основные проверяемые модули:** Авторизация, Каталог товаров (Inventory), Корзина (Cart), Оформление заказа (Checkout), Адаптивная верстка

## 5. Ограничения (Limitations)

- Тестирование проводилось только в браузере Google Chrome на ОС macOS. Кросс-браузерное тестирование (Safari, Firefox, Edge) и тестирование на реальных мобильных устройствах (iOS, Android) не проводилось
- Тестирование проводилось только под учетными записями `standard_user` и `visual_user`
